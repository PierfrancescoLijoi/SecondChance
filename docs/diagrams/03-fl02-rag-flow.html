Grounded answers, or none at all

FR-043 · ADR-003

Security before retrieval

  • Tenant and role are set on the transaction before the first query.
  • RLS filters document chunks exactly as it filters offers.
  • ACL-negative tests must return zero rows, in CI, on every change.

FR-044 · FR-045

Two chances to abstain

  • Weak retrieval: no model call at all, which is cheaper and safer.
  • Grounding score below threshold: abstain, never a best guess.
  • The UI labels every answer as AI-generated (AI Act transparency).

NFR-019

Measured, not assumed

  • Golden set per language: hit@k, faithfulness ≥ 95%, citation correctness ≥ 90%.
  • Reranker and embedding model stay only if they move those numbers.
